# Phase 15 — Final V2 Integration Audit

## Goal

After V2 completion, perform a repository-wide parity and correctness audit.

## Checklist

- First-class Conversation Context; no intent dependency; versioned Query IR; separate planning; real multi-engine execution.
- Adapter-bound Neo4j and Neo4j-backed GraphRAG; raw/canonical separation; common Result & Evidence; no engine persists final answers.
- Stable IDs, conservative merge/history, curation UI, preserved mentions, complete provenance, claim/fact states, retained conflicts, temporal original/normalized values.
- Full rebuild, same-generation readiness, isolation, curated precedence, and no partial activation.
- Query coverage: simple entities, exhaustive operations, grouping/ranking, dates, relations, multi-hop/temporal, conflicts, GraphRAG modes, composition, and follow-ups.
- Docs/System Map/context/project map/status match runtime; stale V1 claims are removed or historical.

## Final output

Report completed architecture, limitations, evaluation results, migration/reindex status, System Map and documentation parity, and V2 acceptance pass/fail.
